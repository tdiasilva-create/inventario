# Prompt de bootstrap do Codex

Você está no repositório `tdiasilva-create/inventario`, que documenta o futuro Sistema de Inventário Tecnológico SEMED.

Antes de qualquer implementação:
1. Leia `AGENTS.md`, `README.md`, `docs/00-governanca/INDICE.md`, `docs/00-governanca/DECISOES.md`, `docs/00-governanca/PENDENCIAS.md` e `design/MANIFESTO_REFERENCIAS.md`.
2. Leia a íntegra de `docs/02-coleta-mobile/BASE_DE_COLETA_V1_0_ORIGINAL.txt` ao trabalhar na coleta.
3. Inspecione visualmente TODOS os PNGs citados no manifesto. A interface mobile aprovada não é uma versão reduzida do desktop.
4. Considere decisões posteriores documentadas como prevalentes. Não reutilize pendências antigas superadas pela Base v1.0.
5. Avalie a estrutura de código existente e apresente **plano de implementação por fases**, sem iniciar uma reescrita total.
6. Para dúvidas não resolvidas, proponha opções explicitamente, sinalize como PENDENTE e prefira arquitetura reversível.
7. Ao implementar, prove fidelidade visual com capturas de tela reais, verifique acessibilidade e execute testes funcionais.

Não invente 90 escolas, coordenadas, dados patrimoniais, perguntas, opções de resposta, credenciais, brasão ou indicadores. Nunca trate screenshot como componente funcional.
