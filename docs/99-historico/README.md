# Documentos de entrada anteriores à organização

Os arquivos em `entrada-anterior-a-organizacao-2026-11-05/` preservam os antigos guias da raiz. São registros históricos, com afirmações de fases anteriores (DEMO, R2, publicação futura) que não representam necessariamente o serviço atual. Seus links relativos mantêm o contexto original da raiz.

Para operar o projeto, começar em [docs/07-operacao](../07-operacao/README.md). As decisões datadas em [DECISOES.md](../00-governanca/DECISOES.md) continuam tendo precedência. A Base de Coleta original não foi movida nem reescrita.

Pacotes recebidos, executáveis, exportações e capturas com dados reais permanecem no armazenamento privado e não acompanham o clone público. A transferência desses materiais deve ocorrer por canal restrito, com responsável, finalidade e hashes registrados.
