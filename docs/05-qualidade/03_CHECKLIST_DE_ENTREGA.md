# Checklist de entrega do pacote e do desenvolvimento

## Conferência documental antes de usar Codex
- [ ] A Base de Coleta original está íntegra e legível.
- [ ] As 6 imagens são originais, acessíveis e têm manifesto SHA256.
- [ ] Documento inicial, AGENTS.md, plano e prompts existem na raiz/pastas esperadas.
- [ ] A separação de mobile e desktop está explícita.
- [ ] Pontos pendentes não foram promovidos a decisões.
- [ ] Identidade visual aprovada remete ao PNG correto e não a imagens decorativas.
- [ ] Nenhum exemplo de escola/percentual foi tratado como dado oficial.
- [ ] GitHub contém os arquivos EXTRÁIDOS, não apenas o ZIP.

## Conferência de aplicação antes de anunciar pronta
- [ ] Autorizações de API verificadas com usuário coletor e admin.
- [ ] Registro contínuo e conferência de equipamento existente, sem duplicidade.
- [ ] Foto câmera/galeria, compressão e upload confirmados R2.
- [ ] Estados do cartão e da vistoria não se confundem.
- [ ] Funcionamento offline e sessão expirada testados em Chrome Android e Safari iPhone reais.
- [ ] Controle de edição concorrente e conflitos offline.
- [ ] Backups D1/R2 e restore trimestral com testes registrados.
- [ ] Pantallas reais comparadas visualmente com as 6 referências.
- [ ] Painel mostra somente oficiais e nunca percentuais simulados.
