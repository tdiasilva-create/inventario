COMO USAR ESTE ARQUIVO
Cada item tem um código e um espaço [   ]. Preencha com:
  M = manter; R = remover da tela; A = alterar; T = transferir para outra tela.
Exemplo: [ T ] PAN-14 ... Destino: Detalhe da unidade.
Exemplo: [ A ] COM-07 ... Mostrar hostname maior e ocultar o ID.
Você pode apagar linhas e escrever novos itens. Para evitar dúvida, prefira
marcar R quando desejar remover e indicar o destino quando mover.
Ao final de cada seção, registre novos itens, ordem e observações.
Remover da interface NÃO significa excluir dados do banco.
As escolhas servirão de base para a próxima implementação.

O QUE ESTA LISTAGEM REPRESENTA
- Itens e ações do código da versão publicada, não uma nova proposta visual.
- Visão completa do root, com diferenças de acesso indicadas por tela.
- Itens condicionais ficam vazios/ocultos se não houver dados ou permissão.
- Nenhum cadastro, foto, conta ou registro foi alterado para gerar este TXT.
- Levantamento por arquivos do painel e documentação de publicação; não é
  nova homologação de cada tela em sessão autenticada no ambiente real.
- Quantidades são dinâmicas; este documento não fixa números de escolas ou bens.

DIFERENÇAS IMPORTANTES PARA DECIDIR A ORGANIZAÇÃO
1. Cadastro mestre: dados registrados pelo root sobre a unidade.
2. Coleta parcial: dados/fotos salvos, mas visita ainda não concluída.
3. Inventário publicado: dados confirmados após conclusão da visita.
4. Telemetria: dados e comunicação enviados pelo agente Windows.
5. Ocorrência da coleta: problema/necessidade do questionário.
6. Demanda: atendimento administrado pela equipe, com situação/histórico.
7. Alerta de hardware: alteração técnica detectada, com parecer.
Os três últimos podem se relacionar, mas não são a mesma lista ou contagem.
