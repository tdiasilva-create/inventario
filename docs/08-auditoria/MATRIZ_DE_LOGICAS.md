## Fluxo que deve ser rastreado ponta a ponta

Unidade oficial → visita aberta → resposta/equipamento com ID → gravação confirmada → consulta PARCIAL → fotografias confirmadas e condições da visita atendidas → conclusão no servidor → ficha publicada/matriz. Em paralelo: instalação assinada → QR/vínculo → telemetria → presença/comparação → notificações. Atendimento manual tem outro ciclo: demanda → ações/histórico → conclusão com relato.

Para cada etapa conferir fonte do dado, ID da unidade/visita/equipamento, autor, versão, persistência e consumidor visual. Seguir a mesma identidade ao editar, transferir localização, revisitar e excluir em ambiente isolado. Não somar versões como se fossem novos bens.
